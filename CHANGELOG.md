## [0.2.1] - 2025-12-07

### Fixed

- Fixed comments not being highlighted properly in unions (by [ShadiestGoat](https://github.com/ShadiestGoat))

## [0.2.0] - 2024-09-16

### Added

- Configuration for `capnp` binary path
- Configuration for import paths
- Configuration for standard imports

### Fixed

- Improved syntax highlighting for
  - Nested interfaces
  - Nested structs
  - Constants
  - Imports
  - Annotations
  - Comments within enums

### Fixed

- Syntax highlighting for:
  - Comments
  - Recursive types within methods
  - IDs on structs and enums
